Hello and welcome!

My name is Julian Rijken and I'm a student game developer. This is my portfolio so feel free to look around.

Train Trouble

What I did:

I was responsible for programming the entire game as a solo developer. I was confronted with buffering lists for the train wagons and because it was the first time I worked with 2 others on a unity projects, I learned a lot about Git in the progress.

About the game:

Train trouble is an action packed local multiplayer game. You have to get as many passengers to their destination while, at the same time, competing against other players.

• Engine: Unity
• Language: C#
• Programmer: Julian Rijken
• Artists: Justin Knobbout, Jonne Keizer
